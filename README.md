## 📌 About the Project  

**NarcStop AI** is a modern web-based anti-narcotics awareness and reporting platform designed to:

- Promote drug awareness and prevention  
- Allow anonymous reporting of suspicious activities  
- Provide rehabilitation and therapy resources  
- Offer emergency SOS assistance  
- Deliver an interactive user dashboard  

The platform focuses on accessibility, awareness, and digital support to combat narcotics-related issues through technology.

## 🚀 How to Run Locally  

### 1️⃣ Clone the repository

```bash
git clone https://github.com/hardik-cs2837/Anti-Narcotics.git
```

### 2️⃣ Navigate into the project folder

```bash
cd Anti-Narcotics
```

### 3️⃣ Open Frontend

Simply open `index.html` in your browser  

OR  

### 4️⃣ Run Backend (if using server)

```bash
npm install
node server.js
```
